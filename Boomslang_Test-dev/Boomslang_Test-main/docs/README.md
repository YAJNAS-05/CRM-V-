# Documentation Index

This repository keeps operational and implementation documents under the docs folder to keep the project root clean.

## Folder Guide

- docs/getting-started

- docs/guides
  - Functional guides and usage references.
- docs/reports
  - Delivery summaries, fix reports, and verification artifacts.
- docs/product
  - Product and planning references (PRD, enhancement notes).
- docs/prompts
  - Development prompt artifacts.
